# Tessera 組圖

把多張照片拼成一張圖的純前端工具。照片只在瀏覽器內處理，不會上傳。

## 功能

- **版型**：1–9 格共 30 種版型；分隔線可拖曳調整比例
- **照片**：點空格選檔、拖放、⌘V / Ctrl+V 貼上；一次多張會自動依序填格
- **格內調整**：拖曳平移、滾輪 / 雙指縮放、雙擊回正；拖出格子外可與其他格交換；旋轉、翻轉
- **邊框**：8 種畫布比例（1:1、4:5、9:16…）、外框、間距、圓角、背景色
- **調色**：9 種濾鏡＋亮度 / 對比 / 飽和度 / 色溫 / 褪色，可一鍵套用到全部
- **文字與貼圖**：6 種字型、4 種樣式；拖曳移動、右下把手縮放旋轉
- **匯出**：1080 / 2K / 4K，JPG 或 PNG；手機可直接開分享面板
- **其他**：復原 / 重做（⌘Z / ⇧⌘Z）、草稿自動存在 IndexedDB、PWA 可離線使用

## 開發

```bash
npm install
npm run serve       # http://localhost:8088
npm test            # vitest：版型 / 幾何 / 擺放 / 調色 / 匯出尺寸
npm run production  # 輸出到 dist/
```

## 架構

- `lib/render.js`：預覽與匯出**共用**同一個 canvas 繪製器，保證所見即所得
- `lib/layouts.js` + `lib/geometry.js`：版型以分割樹描述，攤平成像素位置；尺寸以「短邊千分比」儲存，與輸出解析度無關
- `lib/adjust.js`：調色走像素運算（LUT＋飽和度），不依賴 Safari 支援不穩的 `ctx.filter`
- `lib/photos.js`：照片 Blob、預覽圖、調色快取放在 Pinia 外，避免大物件進響應式系統
- `components/Stage.vue`：canvas 上疊一層 DOM 處理命中區、分隔線、文字選取框
